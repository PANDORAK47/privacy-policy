# 🍎 맥북에서 실행하기 (초보자용)

당신 맥북엔 이미 **API 키**가 있습니다(`SKILL 2/.mcp.json`의 `ifacs-unified`).
아래 순서대로 **터미널에 복사·붙여넣기**만 하면 됩니다. (어려우면 이 문서를 개발자에게 그대로 전달하세요.)

> 💡 지금 보고 계신 클라우드(웹)에서는 당신 맥북 파일·인터넷에 접근할 수 없어서, 진짜 데이터 연결은 **맥북에서** 해야 합니다.

---

## 0. 터미널 열기
`Cmd + Space` → **터미널** 입력 → 엔터. 검은(또는 흰) 창이 뜹니다. 여기에 아래 명령을 한 줄씩 붙여넣고 엔터.

## 1. 코드 내려받기
```bash
cd ~/Downloads
git clone -b claude/great-mendel-wqjrwk https://github.com/PANDORAK47/privacy-policy.git
cd privacy-policy/poc
```
> `git: command not found` 가 뜨면 → GitHub 웹에서 브랜치 `claude/great-mendel-wqjrwk` 선택 → **Code ▸ Download ZIP** → 압축 풀고, 그 안의 `poc` 폴더로 `cd` 하세요.

## 2. 키 자동 설정 (손으로 복사할 필요 없음)
```bash
python3 scripts/setup_local.py
```
- `SKILL 2/.mcp.json`을 자동으로 찾아 키를 읽어 `.env`를 만들어 줍니다.
- 화면엔 **키 길이만**(예: `FSK_API_KEY: 20자`) 뜨고 키 값은 안 보입니다(정상).
- 파일을 못 찾으면 경로를 직접 지정:
  ```bash
  python3 scripts/setup_local.py "/Users/hyunbaekim/Downloads/SKILL 2/.mcp.json"
  ```

## 3. 필요한 부품 설치
```bash
python3 -m pip install -r requirements.txt
```
> `pip` 관련 오류가 나면 `python3 -m ensurepip --upgrade` 후 다시 시도.

## 4. 연결 확인 (실제 응답 보기)
```bash
python3 scripts/api_selftest.py 정제수
```
- `raw row[0] fields: [...]` 가 보이면 **실연동 성공** 입니다 🎉 (그 필드 이름을 저에게 알려주시면 마지막 매핑을 맞춰드립니다.)
- `source: MOCK` 또는 `service_id MISSING` 이 보이면 → 아직 **데이터셋 ID(서비스ID)** 가 비어 있어 연습데이터로 도는 중. (해결법은 아래 ⑥)

## 5. 프로그램 실행
```bash
python3 -m uvicorn app.main:app --reload
```
→ 브라우저에서 **http://localhost:8000** 열기 → `샘플 채우기` → `검증 실행`.
(끄려면 터미널에서 `Control + C`)

## ⑥ "진짜 식품 데이터"까지 연결하려면 (마지막 한 단계)
당신의 **`DATA_GO_KR_API_KEY`(88자)가 식품원료·성분 조회용**이라고 하셨죠. 이 부분은
공공데이터포털(data.go.kr)의 정확한 **요청 주소/서비스ID**가 필요합니다. 가장 빠른 길:

- **이미 잘 도는 `ifacs-unified`가 이 조회를 하고 있다면**, 그 서버가 쓰는 주소/ID를 그대로 알려주세요(또는 만든 분께 문의). → 제가 그 값에 맞춰 코드를 1줄 맞추면 끝.
- 또는 4단계 `api_selftest.py` 출력 결과를 저에게 붙여주시면, 제가 매핑을 확정해 드립니다.

> 그전까지도 프로그램·화면·판정 로직은 **연습데이터로 완전히 작동**하므로, 팀에 시연하거나 흐름을 확인하는 데는 문제없습니다.
